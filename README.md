# News Aggregator
A Python-based News Aggregator project developed using Jupyter Notebook.  
This project uses web scraping techniques to fetch and display latest news headlines from online news websites.

## Features
- Fetches latest news headlines
- Web scraping using BeautifulSoup
- Simple and beginner-friendly project
- Runs in Jupyter Notebook

## Technologies Used
- VS Code
- Python
- Jupyter Notebook
- Requests
- BeautifulSoup4
